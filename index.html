Sheet Connection
The long string between /d/ and /edit in the sheet URL.
Comma separated. Only needed if your tabs aren't named "Form Responses 1–8".
Form links
Paste each Google Form link once. They turn into "file a report" buttons on the matching table, so reps reach the right form from the dashboard.
Open each link before you paste it and check the form title matches the label. A form pointing at the wrong report is the most common reason a tab stays empty.
Making the sheet readable
  1. Open the master doc → Share → General access → Anyone with the link → Viewer
  2. That's it. No script, no token. The dashboard reads it straight from Google.
  3. If it says connected but empty, the sharing setting hasn't taken — recheck step 1.
  4. This only works on a hosted page. Opening index.html off your desktop won't fetch Google Sheets.
Anyone with the dashboard link can see the numbers, and anyone with the sheet link can see the sheet. Keep both to the team.
